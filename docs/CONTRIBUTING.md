# Contributing Guide

## Code Style

- Use TypeScript for type safety
- Follow ESLint and Prettier conventions
- Write tests for new features

## Branch Naming

- `feature/` - New features
- `fix/` - Bug fixes
- `docs/` - Documentation updates

## Commit Messages

Follow conventional commits format:

- `feat:` - New feature
- `fix:` - Bug fix
- `docs:` - Documentation
- `test:` - Tests
